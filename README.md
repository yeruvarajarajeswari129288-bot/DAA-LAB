Summary
This lab practical covers the implementation of five basic sorting algorithms:
Selection Sort, Merge Sort, Bubble Sort, Insertion Sort, and Quick Sort.
Each program accepts input from the user, sorts the given data in ascending order, and displays the execution time 
The practical also includes the time and space complexity of every algorithm, making it easier to compare their performance.
Selection Sort takes quadratic time in all cases.
Bubble Sort and Insertion Sort perform better when the data is already sorted or nearly sorted.
Merge Sort provides consistent performance with logarithmic time growth and uses extra memory, while Quick Sort is very efficient for most inputs but can take more time in the worst case.
This practical gives a clear understanding of how different sorting algorithms process data and how their efficiency varies with different inputs.
